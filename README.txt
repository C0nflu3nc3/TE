WellMatch AI student MVP

Open WellMatch_AI_Prototype.html directly in Chrome, Safari, or Edge. No server or installation is required. All interface text is in English.

Suggested demonstration
1. Accept the optional demo checkbox and start.
2. Enter budget 20, choose Light, choose Yes fragrance-free.
3. Compare Air ($12, 50 mL) and Dew ($18, 100 mL).
4. Select either cream, rate clarity, and explain one reason and one limitation.
5. Save feedback locally and download the session JSON.
6. Restart and try budget 5 for a no-match outcome.
7. Rich and fragrance-free with budget 20 returns Cloud.
8. Light with no fragrance preference and budget 10 returns Bloom.

All four products are fictional. Matching uses explicit rules, not a running AI model. Feedback remains in the current browser tab session and is never uploaded. Time to selection is an observation, not an alpha/beta success result. Human review is required for comprehension. Browser storage may be restricted for local files; the live session can still be downloaded.

Source files: index.html, style.css, app.js. For future hosting, serve them as static files. Online publication was not completed in this session due to network restrictions.
